# Image to WebP v2.5.3

Aplikasi desktop Windows x64 untuk konversi batch gambar ke WebP, AVIF, JPEG, dan PNG, langsung di perangkat.

## Perubahan

- Ikon ImgConv baru: bingkai foto, panah konversi, aksen lime/pink, dan outline hitam.
- Ikon konsisten pada header, taskbar, tray, notifikasi, installer, dan uninstaller.
- Sumber SVG yang dapat diedit serta generator ICO multi-resolusi 16-256 px.

## Unduh

- **Installer:** Image-to-WebP-Setup-2.5.3.exe
- **Portable:** Image-to-WebP-2.5.3.exe
- **SHA256SUMS.txt:** checksum unduhan.

Tidak memerlukan Node.js atau Python. Build belum ditandatangani dengan sertifikat code signing; Windows SmartScreen dapat menampilkan peringatan.

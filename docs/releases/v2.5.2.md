# Image to WebP v2.5.2

Aplikasi desktop Windows x64 untuk mengonversi batch gambar ke **WebP, AVIF, JPEG, dan PNG**. Konversi berjalan lokal, tanpa upload gambar atau akun layanan.

## Download

- **Installer:** `Image-to-WebP-Setup-2.5.2.exe` — pemasangan melalui wizard Windows.
- **Portable:** `Image-to-WebP-2.5.2.exe` — langsung dijalankan tanpa instalasi.
- **SHA256SUMS.txt:** checksum untuk memeriksa integritas unduhan.

`latest.yml` dan `.blockmap` merupakan metadata distribusi; pengguna cukup memilih salah satu file `.exe` di atas. Tidak perlu memasang Node.js atau Python untuk menjalankan aplikasi.

## Fitur dan perubahan

- Antrean utama yang luas, list/grid, thumbnail dan preview, drag-and-drop file/folder, serta pemindaian subfolder.
- Empat format output, kualitas yang dapat diatur, orientasi EXIF otomatis, dan pilihan mempertahankan struktur folder.
- Nama output diklaim secara eksklusif agar batch paralel tidak saling menimpa. File asli tetap dipertahankan.
- Sidebar pengaturan ringkas dan dock aksi/progres yang tetap terlihat saat antrean digulir.
- Buka hasil bekerja untuk output di folder asal; perubahan lokasi output mengaktifkan konversi ulang.
- Tema terang/gelap, font lokal, pintasan keyboard, riwayat, tray, dan menu konteks Windows.
- Perbaikan keamanan log, pembatasan IPC/pengaturan, sandbox, CSP, dan pembaruan dependency.
- WordPress upload beserta credential/API-nya dihapus. Pengaturan WordPress lama dibersihkan saat startup.
- README produk, screenshot, lisensi, panduan kontribusi, CI Windows, dan workflow rilis manual.

## Validasi

Suite regresi konversi/renderer/keamanan/checksum, smoke test Electron, dan pemeriksaan UI beberapa ukuran dijalankan. Axe diperiksa pada tema terang, gelap, Settings, About, dan Preview. Build Windows menyertakan ikon, metadata produk, dan versi 2.5.2.

## Catatan penggunaan

- Build ini **unsigned**. Windows dapat menampilkan peringatan penerbit tidak dikenal atau SmartScreen. Gunakan aset dari repo resmi dan cocokkan checksum.
- Platform rilis: **Windows x64**. Build ARM64, Windows 32-bit, macOS, dan Linux belum tersedia.
- BMP belum didukung. GIF animasi/TIFF multipage menggunakan frame/page pertama; JPEG tidak mempertahankan transparansi.
- Output dapat lebih besar pada format/kualitas tertentu; aplikasi menampilkan perubahannya.
- Saat cancel, pekerjaan yang sudah berjalan diselesaikan dan pekerjaan yang masih mengantre dilewati.
- Menutup jendela menyembunyikannya ke tray. Pilih **Keluar** dari tray sebelum menjalankan versi baru jika versi lama masih aktif.
